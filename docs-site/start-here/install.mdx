---
title: Install Avalanche
description: Choose a starter workspace or add Avalanche to an existing Python project.
---

Choose the path that matches where you are starting. Both paths use the same
local-first Avalanche runtime and can run deterministic Python nodes without a
model provider.

## Requirements

- Python 3.11, 3.12, or 3.13
- [uv](https://docs.astral.sh/uv/)
- An LLM provider API key or Codex subscription only when the workflow uses
  agent steps

## Create a starter workspace

Use a new, empty directory when you want a ready-to-run example, the Avalanche
authoring skill, and provider setup included:

```bash
uvx avalanche-ai init
```

[Create a starter workspace](./starter-workspace), then
[run the included workflow](./run-starter).

## Add Avalanche to an existing project

Use an existing Python project when Avalanche should live alongside application
code:

```bash
uv add avalanche-ai
```

[Add Avalanche to an existing project](./existing-project) for optional skill
installation, provider configuration, and a narrow local run target.
