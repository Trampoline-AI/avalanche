---
title: Create a starter workspace
description: Initialize a ready-to-run Avalanche project with a sample workflow and authoring skill.
---

Use `init` in a new, empty directory when you want Avalanche to prepare a
project and include a working example.

## Initialize the project

```bash
mkdir avalanche-workspace
cd avalanche-workspace
uvx avalanche-ai init
```

The initializer creates project dependencies, the Avalanche authoring skill, a
provider-configuration helper, and the `binary_converter` example workflow.

## Configure a provider

In an interactive terminal, the initializer offers provider setup. If you skip
that prompt, configure it later from the workspace:

```bash
bash scripts/configure-provider.sh
```

## Use editable local dependencies

To develop Avalanche and PredictRLM alongside the new workspace, initialize it
with editable dependencies:

```bash
uvx avalanche-ai init --editable-deps
```

This clones both projects into `.trampoline-ai/` and uses those checkouts as
editable dependencies.
